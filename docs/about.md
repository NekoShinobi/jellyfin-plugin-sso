# About and credits

This fork continues [9p4/jellyfin-plugin-sso](https://github.com/9p4/jellyfin-plugin-sso),
which was archived upstream. Existing code and documentation retain their
[GPL-3.0 license](https://www.gnu.org/licenses/gpl-3.0.html).

The original plugin drew on the
[Jellyfin LDAP plugin](https://github.com/jellyfin/jellyfin-plugin-ldapauth).
Its original SAML implementation was adapted from
[AspNetSaml](https://github.com/jitbit/AspNetSaml), and has been replaced with [ITfoxtec Identity SAML2](https://github.com/ITfoxtec/ITfoxtec.Identity.Saml2).
OIDC uses
[Duende IdentityModel OIDC Client](https://github.com/DuendeSoftware/foss).

Thanks to the upstream authors and contributors for the plugin, provider
recipes, translations of provider behavior into practical setup instructions,
and issue reports. Provider screenshots in this documentation are historical
upstream screenshots, not evidence of current Jellyfin 12 validation.
